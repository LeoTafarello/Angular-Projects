# Angular Projects

Repository containing various Angular projects.

## Projects

### Financial Calculator
A financial calculator application built with Angular.

**Location:** ./financial-calculator/

#### Getting Started

1. Navigate to the project directory:
   \\\Bash
   cd financial-calculator
   \\\

2. Install dependencies:
   \\\Bash
   npm install
   \\\

3. Start the development server:
   \\\Bash
   ng serve
   \\\

4. Open your browser and navigate to \http://localhost:4200/\

#### Building for Production

\\\ash
ng build --configuration production
\\\

For more details, see [financial-calculator/README.md](./financial-calculator/README.md)
